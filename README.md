One new English word, defined in a single clear line of at most 140 characters. The word fills a real gap: every heavy browser user knows the feeling, but no word for it exists.

## The word

> Tabnado (n.) — the storm of 87 open browser tabs that spins up the moment you try to find the one tab you actually need.

Tab + tornado: sayable, spellable, memorable.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network, no input files, no secrets.
